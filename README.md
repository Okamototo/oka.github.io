# Sora Clock（iPhone 8 Plus 用 時計＋天気）

作成日：2026-11-09

## 中身
- `index.html` … アプリ本体（1ファイルで完結）
- `apple-touch-icon.png` … ホーム画面用アイコン

## できること
- 大きなデジタル時計（秒・日付・曜日つき。土曜は青、日曜は赤）
- 現在地の天気：気温・天気・最高/最低・体感・湿度
- 5時間先までの1時間ごと予報（降水確率20%以上を表示）
- 明日から3日間の予報
- 天気は15分ごとに自動更新。画面タップでも更新
- 23時〜6時は画面を自動で暗めにする
- 通信が切れても最後に取得した天気を表示（「オフライン」と表示）
- 位置情報を許可しない場合は東京の天気を表示

## 設置手順
1. HTTPSで配信する（位置情報はHTTPS必須）。おすすめは GitHub Pages：
   - GitHubで `ユーザー名.github.io` という公開リポジトリを作る
   - `index.html` と `apple-touch-icon.png` をアップロード
   - Settings → Pages → 「Deploy from a branch」で main を選ぶ
   - 数分後 `https://ユーザー名.github.io/` で開ける
2. iPhone 8 Plus の Safari でそのURLを開き、位置情報を「許可」
3. 共有ボタン → 「ホーム画面に追加」（全画面で表示される）
4. 設定 → 画面表示と明るさ → 自動ロック → 「なし」
5. 充電ケーブルをつないだまま、スタンドに横向きで立てる

## 注意
- iPhone 8 Plus は iOS 16 までのため、ホーム画面から開いた場合はブラウザの「画面を消さない機能（Wake Lock）」が効きません（iOS 18.4で修正）。常時表示は手順4の自動ロック「なし」で行ってください。
- 天気データは Open-Meteo（非商用は無料・キー不要、CC BY 4.0で出典表記が必要）。画面右下に出典を表示しています。
- 設定を変えたい場合は `index.html` 冒頭の「設定」部分（更新間隔・暗くする時間帯・位置情報なし時の地点）を編集します。
